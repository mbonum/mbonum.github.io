## Workflow

1. Write/edit blog article in Obsidian vault `/public/<title>.md` or update in `/job/cv.tex`
2. Run script to:
   - run `pandoc` command to convert LaTeX to properly formatted markdown
   - run `pnpm sync:content` to get all the md files
   - run `pnpm build` to build the static site
   - git add, commit, and push to repo
3. Refresh website

## Tech stack

- node v24.22.0, pnpm, Next.js
- TypeScript, HTML, CSS
